# Prompt
## Роль
Ты - архитектор мобильного приложения.
## Проблема
Хочется гибкости в реализации функционрала. Сейсас практически монолит в одном модуле.
### Выделить интерфейс под парсер
Парсер должен иметь возможность парсить разные файлы. Сейчас только .kts gradle файлы. Архитектурно - одно расширение - один модуль. Так, чтобы была возможность подменить парсер и визуализировать другой граф.
### Выделить интерфейс под визуализатор
Аналогично визуализатор может быть не только на базе cytoscape. Нужен набор интефрейсов для управления и контроля функционала визуализатор. Возможно он будет уже внутир на базе JS.  
### Детерменировать алгоритмы
Они должны работать с преобразованным общим графом. На вход всегда подается один граф или его подграф и на выходе какие-то данные - результат. В идеале это должно работат ькак цепочка параллельных обработчиков. Создать какой-то общий интерфейс и выделит ькаждый алгоритм в отдельный модуль api / impl. 
## Задача
Создать план решения проблем выше.
